# CourtSide

Pickleball scorekeeper + round robin with a realistic court view.

**Live app:** https://vensad.github.io/courtside/

## Features
- Side-out & rally scoring with classic **0-0-2** call
- Tap court sides to score (serving side = point, other = side out)
- Round robin + Winners Stay formats
- Quick Start with random player names
- Saved player groups
- 2D / 3D court view

## Install on iPhone
1. Open the live link in **Safari**
2. Share → **Add to Home Screen**

## Enable GitHub Pages
1. Open **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / folder: **/ (root)**
4. Save — live in about a minute at https://vensad.github.io/courtside/
